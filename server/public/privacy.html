Together — приложение для ведения личного дневника парой, с еженедельным AI-разбором. Эта страница описывает, какие данные мы собираем, зачем, и с кем ими делимся.

Какие данные мы собираем

  • Данные аккаунта: email, имя, пароль (хранится только в виде необратимого хеша, никогда в открытом виде) или идентификатор Apple при входе через Sign in with Apple.
  • Профиль: аватар (эмодзи или фото), дата начала отношений, языки любви, интересы, часовой пояс, дата рождения, профессия, привычки, город — все поля профиля необязательны и заполняются по желанию.
  • Записи дневника: текст, эмоция, тип записи, теги, прикреплённые фото.
  • Данные пары: код приглашения, статус пары, кто ваш партнёр в приложении.
  • Еженедельные отчёты: AI-сгенерированный разбор недели на основе записей обоих партнёров.
  • Push-токен устройства — для отправки уведомлений.
  • Технические данные при сбоях — через Sentry: тип ошибки, версия приложения, техническая информация об устройстве. Текст ваших записей в эти данные не попадает.

Как мы используем данные

  • Чтобы показывать ваши записи и записи партнёра друг другу (согласно правилам приложения — партнёр видит запись только после того, как она попадёт в еженедельный отчёт).
  • Чтобы сгенерировать еженедельный AI-разбор: текст записей обоих партнёров этой недели передаётся в OpenAI (поставщик AI-модели) для создания связного повествования. OpenAI обрабатывает эти данные согласно их политике использования данных API и не использует их для обучения моделей.
  • Чтобы определить погоду в отчёте, город из вашего профиля передаётся сервису Open-Meteo (без привязки к имени, email или другим личным данным).
  • Чтобы отправлять push-уведомления через Expo Push Notification Service.
  • Чтобы находить и исправлять ошибки — через Sentry.

С кем мы делимся данными

Мы не продаём ваши данные. Мы передаём данные только следующим поставщикам услуг, необходимым для работы приложения:

  • OpenAI — обработка текста записей для генерации отчёта.
  • Apple — если вы используете Sign in with Apple.
  • Expo — доставка push-уведомлений.
  • Open-Meteo — исторические данные о погоде по названию города.
  • Sentry — отслеживание технических ошибок.
  • Ваш партнёр в приложении — видит записи, которые попали в общий еженедельный отчёт, а также ваше имя, аватар и статус активности.

Хранение данных

Данные хранятся на серверах [НАЗВАНИЕ ХОСТИНГ-ПРОВАЙДЕРА / РЕГИОН] столько, сколько существует ваш аккаунт. Фотографии хранятся вместе с записью, к которой они прикреплены.

Ваши права

  • Доступ к данным: в настройках профиля есть кнопка «Экспортировать мои данные» — она формирует полный файл со всеми данными, которые мы храним о вас.
  • Удаление аккаунта: в настройках профиля есть кнопка «Удалить аккаунт». Это необратимо удаляет ваш аккаунт, все записи и расторгает пару с партнёром.
  • Жители ЕС и Калифорнии имеют дополнительные права по GDPR/CCPA — свяжитесь с нами по адресу ниже.

Дети

Together не предназначено для лиц младше 16 лет. Мы сознательно не собираем данные от детей.

Изменения политики

Мы можем обновлять эту политику. Существенные изменения будут отражены в приложении.
